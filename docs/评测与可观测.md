# 评测与可观测

## 1. Mock 轨迹门禁（CI）

`tests/test_agent_eval_cases.py` 使用 23 个 mock 任务，覆盖：

- 正常工具调用
- 非法参数
- 超时/瞬时失败重试
- 重复动作
- research 审批/拒绝
- 预算耗尽
- 无证据低置信回答

CI 断言 pass^k、工具序列、禁止工具和政策违规为 0。

## 2. 真实评测（手动）

```bash
python scripts/eval_agent_live.py --limit 5 --k 1
python scripts/eval_agent_live.py --json --include-approval
```

输出：

- `pass_pow_k`
- completed/awaiting/rejected rate
- tool sequence match
- policy violation rate / forbidden calls
- avg steps / latency / tokens

真实评测依赖外部 LLM 和工具，不进入 CI。

## 3. Prometheus 指标

Agent：

- `bagent_agent_runs_total`
- `bagent_agent_steps_total{tool,status}`
- `bagent_agent_tool_retries_total`
- `bagent_agent_approvals_total`
- `bagent_agent_operations_total{state}`
- `bagent_agent_recovery_total{status}`
- `bagent_agent_worker_last_scan_timestamp_seconds`

MCP：

- `bagent_mcp_gateway_calls_total{server,tool,status}`

推荐告警：

- `unknown_outcome` 持续增长
- recovery failed > 0
- worker 最近扫描时间超过轮询间隔的 3 倍
- schema_changed 事件出现

## 4. OTel

默认 `OTEL_ENABLED=false`。安装 `requirements-otel.txt` 后：

```dotenv
OTEL_ENABLED=true
OTEL_SERVICE_NAME=bagent-agent
OTEL_EXPORTER_OTLP_ENDPOINT=http://collector:4318
```

Agent/chat/tool span 已接入；默认不采集 prompt、工具参数和结果内容。

## 5. 身份与授权

- `AUTH_ENABLED=false` 保持本地兼容。
- HS256 模式使用 `JWT_SECRET`。
- 设置 `OIDC_JWKS_URL` 后使用 JWKS 验签 RS256/ES256，并校验 issuer/audience/exp。
- Agent 端点检查 run owner；MCP 端点检查 `agent:mcp` scope。
